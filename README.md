## Explore the Portfolio

### [Week 1 — Lab Setup](<WEEK%201/README.md>)
**Objective:** Establish a working environment for practical cybersecurity exercises.

Set up Kali Linux within VirtualBox and prepared the virtual environment for security testing and technical exercises. This week focused on understanding the lab setup, configuring the testing environment, and preparing the tools needed for subsequent activities. The result was a dedicated virtual lab for practising cybersecurity techniques in a controlled environment.

### [Week 2 — Footprinting & Network Reconnaissance](<WEEK%202/README.md>)
**Objective:** Practise information gathering and identify network and web technologies.

Performed reconnaissance exercises involving network scanning, DNS enumeration, domain information gathering, and web technology identification. Worked with tools including Nmap, Zenmap, WHOIS, DNSRecon, Nslookup, WhatWeb, cURL, and Wafw00f. Documented the commands, observations, and scan results to develop practical familiarity with reconnaissance workflows and technical evidence collection.

### [Week 3 — Password Security](<WEEK%203/README.MD>) 
**Objective:** Explore password-security assessment through practical exercises.

Worked on password-security exercises to understand assessment techniques and how password-related testing can be performed in a controlled environment. Focused on following the exercise methodology, observing the results, and documenting the process. This work developed practical familiarity with password-security concepts and the importance of recording evidence and interpreting results accurately.

### [Week 4 — Web Application Security Assessment](<WEEK%204/README.md>)
**Objective:** Apply black-box testing techniques to web security assessment exercises.

Performed black-box web security assessment activities using reconnaissance and web-testing techniques to examine the available information and identify potential security concerns. Focused on documenting the assessment process, recording observations, organizing supporting evidence, and presenting the results in a technical report. The work reinforced structured testing, evidence-based analysis, and clear security documentation.
